### Why the order deviates from code → proofs → docs

before it would be a proof of an ancestor. RV-9 therefore lands with the deliverables, and the full
harness run for RV-7 is captured at the final repo tip. Every remaining claim fix (RV-1/2/3) is in
`instant/`, which is not under version control here and cannot move the tip.

### RV-5 — the finding is right, the prescribed remedy is not

The defect reproduces: `**OSS PR**: #760x` prints `OK companion 760`. But anchoring the number with
`$` as prescribed turns away three inputs the gate accepts today and should keep accepting:

| input | current | `$` anchor (prescribed) | boundary anchor (applied) |
|---|---|---|---|
| `…/pull/760/files` | 760 | refused | 760 |
| `#760 (merged)` | 760 | refused | 760 |
| `#760` + CRLF line ending | 760 | refused | 760 |
| `#760x` (the defect) | 760 | refused | refused |

None of the 23 existing cases covers a passing body with anything after the digits, so the suite
would have gone green on the regression. Applied instead: require the digits to be followed by a
non-alphanumeric character or end of line — `(#|pull/)[0-9]+([^0-9A-Za-z]|$)`. Recorded `applied`
with the deviation named.
